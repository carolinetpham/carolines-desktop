## 3Stones  
**UX Engineer | Sept 2025 – Dec 2025**  
**Focus:** Responsive systems design, cross-platform consistency, implementation-ready handoff

### Overview
3Stones is a responsive web experience designed for a real-estate startup to extend its existing mobile product into desktop and tablet contexts while maintaining brand continuity and familiar interaction patterns.

### UX Problem
The product ecosystem existed primarily on mobile. Transitioning to web introduced:
- Different user behavior (longer browsing sessions, comparison-heavy exploration)
- Larger layouts requiring multi-column hierarchy
- Risk of interaction inconsistency across platforms

### My Role
- Translated mobile interaction patterns into scalable web behaviors
- Designed responsive layouts across key breakpoints
- Clarified information hierarchy for desktop browsing contexts
- Documented component behavior and interaction states for engineering handoff

### UX Approach
- Conducted a product audit to identify reusable interaction patterns
- Created low-fidelity layout explorations to test scanning order and decision flow
- Defined responsive rules for stacking, filtering, and detail views
- Iterated based on stakeholder and developer feedback
- Authored interaction specifications including edge cases and responsive states

### Outcome
Delivered a cohesive, scalable web UX foundation aligned with the existing mobile ecosystem, reducing ambiguity during implementation and supporting long-term system consistency.
