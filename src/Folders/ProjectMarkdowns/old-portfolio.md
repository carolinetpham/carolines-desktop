## Old Personal Portfolio  
**Front-End Foundations | Early React Build**  
**Focus:** Design-to-development translation, foundational UX implementation

### Overview
This was my first fully built personal portfolio, created after attending a Women in Technology Website Hack Day. The project marked my transition from primarily design-focused work into hands-on front-end implementation.

### Context
Starting from a Figma concept, I translated static mockups into a live, responsive website using React, Bootstrap, and JavaScript. This project served as my introduction to bridging UX design decisions with real implementation constraints.

### My Role
- Designed the initial visual direction and layout system in Figma  
- Translated high-fidelity mockups into reusable React components  
- Implemented responsive behaviors using Bootstrap  
- Built a clear contact pathway to support recruiter outreach  

### UX Focus
- Prioritized clarity and hierarchy while experimenting with expressive visual styling  
- Structured project sections to support recruiter scan behavior  
- Learned to balance personality with readability and usability  
- Identified areas where visual density could be reduced to improve clarity  

### Key Learnings
- Moving from static design files to production UI requires trade-offs and system thinking  
- Framework constraints influence spacing, layout behavior, and scalability  
- Visual styling should reinforce — not compete with — content clarity  
- Clean component structure supports long-term maintainability  

### Why I Rebuilt It
While this portfolio met my initial goals, it revealed the limits of a static, section-based layout. It motivated me to design a more interaction-forward, systems-driven portfolio that better reflects my growth in UX strategy and front-end architecture.
