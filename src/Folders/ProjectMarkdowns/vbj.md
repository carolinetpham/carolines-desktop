## Virtual Bullet Journal  
**Object-Oriented Design | CS 3500 Final Project**  
**Focus:** Interaction clarity, information architecture, maintainable system design

### Overview
Virtual Bullet Journal is a desktop planning application designed to translate the flexibility of analog bullet journaling into a structured, persistent digital system. The project demonstrates how interaction design decisions must align with architectural planning to create scalable, usable software.

### UX Problem
Analog bullet journaling offers high flexibility and personal control, but most digital planners sacrifice customization for rigid templates. The challenge was to design a digital experience that:

- Preserves user flexibility  
- Maintains clear weekly structure  
- Supports fast task entry and updates  
- Allows persistent save/load without compromising usability  

### My Role
- Contributed to system architecture planning using UML diagrams  
- Designed task and event creation flows for clarity and speed  
- Structured weekly layout for high scanability  
- Implemented core features within a JavaFX GUI  
- Applied object-oriented design principles to maintain clean separation of concerns  

### UX Strategy
- Prioritized low-friction task/event creation  
- Structured layout around weekly mental models rather than abstract database views  
- Designed predictable interaction patterns to reduce cognitive load  
- Ensured visual hierarchy supported quick scanning and editing  

### System Architecture
- Model-View-Controller (MVC) separation  
- JavaFX-based GUI implementation  
- SOLID principles for modular, maintainable code  
- File persistence logic to support journal state continuity  

The architectural decisions were directly informed by UX goals — ensuring that system structure supported interaction clarity rather than constraining it.

### Execution
- UML modeling before implementation  
- Iterative feature implementation and debugging  
- Validation of save/load edge cases  
- Refinement of layout spacing and task organization for usability  

### Outcome
Delivered a fully functional virtual planner that bridges interaction design and scalable object-oriented architecture. The project demonstrates the ability to connect UX thinking with disciplined system design and maintainable code structure.
