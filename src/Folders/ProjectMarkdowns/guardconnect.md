## GuardConnect  
**UX Strategy + Product Design | September 2025 – December 2025**  
**Focus:** Workflow clarity, large-scale user systems, accessibility-driven design

### Overview
GuardConnect is a communications and mentorship platform designed to improve transparency, career navigation, and resource discoverability for 4,000+ Guardsmen. The project focused on reducing ambiguity in complex institutional workflows and translating stakeholder requirements into scalable, production-ready UX systems.

### UX Problem
Career progression, mentorship access, and communication channels were fragmented across systems, making it difficult for users to:
- Understand available opportunities  
- Identify next steps in career pathways  
- Locate mentorship and communication resources  
- Navigate processes without institutional insider knowledge  

The lack of workflow clarity created friction, uncertainty, and cognitive overload for users.

### My Role
- Led stakeholder interviews to uncover workflow breakdowns and system constraints  
- Mapped high-priority end-to-end user journeys to identify ambiguity and friction points  
- Designed wireframes and high-fidelity prototypes for critical task flows  
- Authored interaction specifications and reusable design tokens  
- Conducted WCAG-aligned accessibility audits and documented remediation guidance  

### UX Strategy
- Reduced cognitive load by restructuring navigation around user goals rather than organizational hierarchy  
- Clarified action hierarchy within high-impact workflows  
- Increased mentorship discoverability through structured entry points  
- Designed system-consistent UI patterns aligned with implementation constraints  
- Embedded accessibility considerations into layout, contrast, and interaction patterns from the start  

### Cross-Functional Collaboration
Partnered closely with product managers and engineers in a Next.js environment to ensure design decisions were technically feasible and production-ready. Maintained alignment between UX intent and implementation through clear documentation and iterative feedback loops.

### Execution
- End-to-end workflow diagrams  
- Wireframes and interactive high-fidelity prototypes  
- Accessibility review documentation  
- Design token definitions to support scalable UI consistency  

### Outcome
Delivered a production-ready UX foundation that improved workflow clarity, strengthened mentorship discoverability, and embedded accessibility into core interaction patterns. The result was a more intuitive, goal-oriented system designed to scale across thousands of users.
